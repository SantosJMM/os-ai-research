# Unidad 10 — Fundamentos de agentes de IA

[Issue #11](https://github.com/SantosJMM/os-ai-research/issues/11)

## Preguntas
- ¿Qué distingue un modelo de un agente y de un runtime?
- ¿Qué ocurre cuando un modelo propone una llamada a herramienta?
- ¿Cómo gestionar sesiones, cancelación, reintentos, memoria, contexto y errores?
- ¿Qué partes pueden verificarse por pruebas deterministas?

## Experimento propuesto
Implementar un bucle de agente con un proveedor simulado, dos herramientas de solo lectura y un registro de eventos. Forzar escenarios de error, timeout y cancelación. No se requiere API de pago.

## Entregables
Diagrama, código, pruebas, estados observados y límites. Comparar posteriormente con Capsuleer sin modificar su implementación.
