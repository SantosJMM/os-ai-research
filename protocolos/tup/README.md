# TUP — nombre anterior de SASP

> **Este documento es una referencia histórica.** La investigación anteriormente denominada **Thanos UI Protocol (TUP)** fue renombrada a **SASP — Semantic Application & Service Protocol** el **21 de noviembre de 2026**, para reflejar su alcance entre aplicaciones y servicios con o sin interfaz gráfica, independiente de Thanos OS.

## Documentación vigente

- [SASP — Semantic Application & Service Protocol](../sasp/README.md)
- [Decisión de nombre y alcance](../sasp/DECISION-0001-nombre-y-alcance.md)
- [Issue #13 — SASP](https://github.com/SantosJMM/os-ai-research/issues/13)

La propuesta original TUP exploraba estado, métodos, eventos, contexto de interfaz y distintas formas de transporte. La idea se conserva bajo SASP, pero la especificación aún está en investigación.

Para consultar el texto original de TUP, utiliza el [historial Git de este archivo](https://github.com/SantosJMM/os-ai-research/commits/master/protocolos/tup/README.md). La ruta antigua se mantiene para facilitar referencias y enlaces anteriores.
