# Roadmap de aprendizaje

No es una secuencia rígida: cada bloque incluye teoría, código fuente, un experimento y conclusiones.

- [ ] 01. CPU, privilegios, interrupciones y syscalls
- [ ] 02. Procesos, hilos, planificación y sincronización
- [ ] 03. IPC: sockets, pipes, memoria compartida y Schemes
- [ ] 04. Memoria virtual, paginación y asignación
- [ ] 05. VFS, archivos, dispositivos y persistencia
- [ ] 06. Seguridad: aislamiento, capacidades, LSM y verificación formal
- [ ] 07. Kernel Rust mínimo y entorno QEMU
- [ ] 08. Comparar Linux, Redox, Asterinas y seL4
- [ ] 09. IA como participante de primera clase del sistema operativo

## Primera práctica sugerida

Comparar un servidor petición-respuesta por socket Unix con un proveedor Scheme de Redox. Medir y documentar funcionalidad, permisos, latencia y coste de implementación, sin anticipar un ganador.
