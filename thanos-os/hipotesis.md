# Hipótesis de investigación: Thanos OS

¿Puede un sistema operativo integrar un agente de IA como participante de primera clase, capaz de observar, razonar y solicitar acciones, sin concederle privilegios directos ni eliminar el control humano?

## Principios de contraste

- La IA no recibe privilegios de kernel por defecto.
- Las operaciones privilegiadas requieren autorización y auditoría.
- Las restricciones deben mantenerse aunque el agente se comporte incorrectamente.
- Se evalúan confiabilidad, recuperabilidad, portabilidad y seguridad.

El código fuente y las decisiones oficiales permanecen en el proyecto Thanos OS; aquí se documentan experimentos y vínculos a evidencias.
